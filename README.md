
# Quizzy - JavaScript Quiz App

Quizzy is a responsive interactive quiz application built using HTML, CSS, and Vanilla JavaScript.

## Features

- 10 multiple-choice questions
- One question at a time
- Instant answer feedback
- Previous and next navigation
- Automatic score calculation
- Progress bar
- Final score and percentage
- Performance messages
- Detailed answer review
- Restart quiz
- Persistent dark and light themes
- Best score stored using localStorage
- Responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Project Structure

```text
JAVASCRIPT-QUIZ/
├── index.html

└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Click Start Quiz to begin.

## Storage

Quizzy uses browser localStorage to remember the selected theme and the highest quiz score.
